# 業務日報表（RWD）

前台：手機打開就能填日報表。
- 姓名、部門（只填一次，下次自動帶入）
- 時間自動帶入（送出當下時間為準）
- 地點（必填，用來確認有沒有到）：GPS 打開自動帶入、送出時強制再重抓一次最新位置（不用舊位置），存緯度、經度、定位時間與 Google 地圖連結；沒有定位就送不出去。
- 客戶地址（必填，由業務自己輸入）：前台除了拜訪地點，還要由業務自己打客戶地址，主管拿來跟 GPS 比對。清單上的地址不會自動帶入這一欄，只用來查座標、做距離判定。
- 自動到達判定：客戶地點清單放在 `locations.js`（名稱＋地址＋緯度＋經度＋判定範圍，預設 200 公尺）。清單有資料時，前台變成下拉選地點，抓到定位就自動算距離，顯示已到達／未到達，送出時把目標、距離、判定一起寫入；清單還沒給時，前台自動退回手填模式，後台顯示未判定、由主管人工比對。
- 工作內容、狀態：進行中／已完工／待追蹤

後台（`admin.html`，連結不要公開貼出）：
- 預設看今天的明細
- 按日期查當日、按月份查整月、按姓名／部門關鍵字再篩
- 匯出目前查詢結果 CSV（含地圖連結）
- 刪除單筆（刪除前建議先匯出備份）

資料庫：Google 試算表「業務日報表」＋ Apps Script（`Code.gs`），程式放 GitHub Pages、資料放 Google，跟朋友生日小站、咖啡進貨紀錄同一模式。
後台密碼是存在主管自己手機／電腦上的簡易鎖，不是銀行級帳號，保密靠不公開後台連結、不把解鎖後的手機借人。
